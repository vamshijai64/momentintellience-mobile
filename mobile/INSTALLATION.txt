====================================================================
               CRICVISION AI MOBILE APP & AWS DEPLOYMENT GUIDE
====================================================================

PROJECT OVERVIEW:
CricVision AI is a React Native (Expo SDK 52) mobile application for
cricket batting analysis, pose estimation, and biomechanical coaching,
connected to a FastAPI Python backend.

--------------------------------------------------------------------
1. PREREQUISITES
--------------------------------------------------------------------
- Node.js (v18.x or v20.x installed on your PC)
- npm (installed with Node.js)
- Expo Go App (Installed on Android / iOS phone from Play Store or App Store)
- AWS EC2 Ubuntu Server (for Cloud Backend Deployment)

--------------------------------------------------------------------
2. MOBILE APP SETUP & RUNNING
--------------------------------------------------------------------
Step 1: Open Terminal / Command Prompt and navigate to the mobile folder:
        cd d:\momentintellience-mobile\mobile

Step 2: Install project dependencies:
        npm install

Step 3: Verify / Configure API URL:
        File: mobile/src/services/api.ts
        
        Live AWS Cloud Backend (Current Config):
        export const CUSTOM_API_URL: string | null = 'http://54.183.208.156:8000/api/v1';

Step 4: Start the Expo Metro Server:
        npx expo start

Step 5: Connect Mobile Phone:
        - Open Expo Go app on your mobile phone.
        - Scan the QR code displayed in your terminal.

--------------------------------------------------------------------
3. AWS EC2 UBUNTU BACKEND SERVER DEPLOYMENT (COMPLETE PROCESS)
--------------------------------------------------------------------
Step 1: SSH into your AWS EC2 Ubuntu Server from Windows CMD:
        icacls momentintelligence.pem /reset
        icacls momentintelligence.pem /inheritance:r
        icacls momentintelligence.pem /grant:r "%USERNAME%:R"
        ssh -i momentintelligence.pem ubuntu@54.183.208.156

Step 2: Install Docker & Git on Ubuntu Server:
        sudo apt update && sudo apt upgrade -y
        sudo apt install -y git curl nginx certbot python3-certbot-nginx
        curl -fsSL https://get.docker.com -o get-docker.sh
        sudo sh get-docker.sh
        sudo usermod -aG docker $USER
        newgrp docker

Step 3: Clone Code & Navigate to Backend:
        git clone -b vamshi_dev https://github.com/vamshijai64/momentintellience-api.git
        cd momentintellience-api/backend

Step 4: Configure .env File on Server:
        nano .env
        
        Paste:
        PROJECT_NAME="Moment Intelligence"
        SECRET_KEY="moment-intelligence-secret-key-prod-2026"
        DATABASE_URL="sqlite+aiosqlite:///./moment_intelligence.db"
        STORAGE_TYPE="local"
        CORS_ORIGINS=["*"]
        
        (Save: Ctrl+O -> Enter -> Ctrl+X)

Step 5: Create Real Database File:
        touch moment_intelligence.db

Step 6: Build & Run Docker Container:
        docker compose up -d --build

Step 7: Check Container Logs & Status:
        docker compose ps
        docker compose logs -f

--------------------------------------------------------------------
4. USEFUL MANAGEMENT COMMANDS ON UBUNTU SERVER
--------------------------------------------------------------------
- Pull latest changes & rebuild:
  git pull origin vamshi_dev
  docker compose up -d --build

- View live application logs:
  docker compose logs -f

- Restart backend container:
  docker compose restart
